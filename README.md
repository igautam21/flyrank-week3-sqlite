# Week 3 SQLite CRUD API

A CRUD Task API built with:

- Express.js
- SQLite (better-sqlite3)
- Swagger UI

## Installation

```bash
npm install
node server.js
```

## API Documentation

http://localhost:3000/docs

## Endpoints

- GET /tasks
- GET /tasks/:id
- POST /tasks
- PUT /tasks/:id
- DELETE /tasks/:id
